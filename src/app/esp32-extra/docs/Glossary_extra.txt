9. TIMEZONES.FTH - Time Zone Definitions
================================================================================

  Time zone data is stored as compact records in flash memory.
  Each time zone record contains:
    - UTC offset (with DST shift)
    - DST start and end rules (date, time, weekday)
    - Northern/Southern hemisphere flag

  Defining a time zone:
  ---------------------
    incr-tz               ( -- )
      Increment time zone counter (call before each new time zone).

    utc-only,             ( utc-offset -- )
      Define a time zone without DST (e.g., UTC, Japan, China).
      Example: create Japan 9 utc-only,

    16bneg                ( -- constant )
      Constant for negative 16-bit values in time zone data.

  Time zone variables:
  --------------------
    #tz                   ( -- addr )
      Time zone counter variable.

    tz-local              ( -- )
      Deferred word for the active local time zone.
      Example: ' Europe/Amsterdam is tz-local

  Displaying time zones:
  ----------------------
    tz-Endlist            ( -- addr )
      Get end of time zone list.

    .tz-header            ( -- )
      Display time zone table header.

    .time-date-dst        ( &tz-weekday-date year -- )
      Display DST date and time for a time zone.

    .summer-time          ( tz-list-item year -- )
      Display summer time (DST) transition details.

    .list-summer-times    ( year -- )
      List all DST transitions for all defined time zones.

    shorten-tz-name       ( addr len -- short )
      Shorten time zone name (e.g., "America/New_York" → "New_York").

    date>jjjjmmdd         ( d m y -- jjjjmmdd )
      Format date as YYYYMMDD number.

  Predefined time zones:
  ----------------------
    UTC                   ( -- tz )
      Coordinated Universal Time (no DST).

    South-Africa          ( -- tz )
      UTC+2, no DST.

    Japan                 ( -- tz )
      UTC+9, no DST.

    China                 ( -- tz )
      UTC+8, no DST.

    Europe/London         ( -- tz )
      UTC+0 with DST (GMT/BST).

    Europe/Amsterdam      ( -- tz )
      UTC+1 with DST (CET/CEST).

    Europe/Moscow         ( -- tz )
      UTC+3, no DST.

    America/New_York      ( -- tz )
      UTC-5 with DST (EST/EDT).

    America/Chicago       ( -- tz )
      UTC-6 with DST (CST/CDT).

    America/Arizona       ( -- tz )
      UTC-7, no DST (MST).

    America/Sao_Paulo     ( -- tz )
      UTC-3, no DST.

    Australia/Melbourne   ( -- tz )
      UTC+10 with DST.

    New_Zealand           ( -- tz )
      UTC+12 with DST.

    Israel                ( -- tz )
      UTC+2 with DST.

    Egypt                 ( -- tz )
      UTC+2 with DST.

    Chile                 ( -- tz )
      UTC-3 with DST (southern hemisphere).

    Paraguay              ( -- tz )
      UTC-3, no DST.

    cuba                  ( -- tz )
      UTC-4 with DST.

    palestine             ( -- tz )
      UTC+2 with DST.

    Lebanon               ( -- tz )
      UTC+2 with DST.

    moldova               ( -- tz )
      UTC+2 with DST.

    Greenwich-Mean-Time   ( -- tz )
      UTC+0, no DST.

    (add new time zones before tz-Endlist)

10. TIMEDIFF.FTH - Time Calculations
================================================================================

  This file provides date/time conversion and calculation functions.
  It uses the Julian Day Number (JDN) system for date arithmetic.

  Constants:
  ----------
    #SecondsOneDay        ( -- F: seconds )
      Seconds in one day (86400.0).

    #SecondsOneHour       ( -- n )
      Seconds in one hour (3600).

  Date/Time conversion:
  ---------------------
    jd                    ( dd mm yyyy -- julian-day )
      Convert Gregorian date to Julian Day Number.

    gregorian-leap-year?  ( year -- flag )
      Check if year is a leap year.

    fixed-from-gregorian  ( day month year -- fixed-date )

13. SCHEDULE-TOOL.FTH - Schedule Management
================================================================================

  This tool provides a scheduling system for time-based events.
  It uses two tables: a schedule table and an options table.

  Schedule table structure (per record):
    - Time: HHMM format (4-digit integer)
    - Option: Index into options table

  Options table structure (per record):
    - XT: Forth word to execute
    - Description: Menu text for web interface

  Constants and variables:
  ------------------------
    &schedule-file        ( -- addr )
      Pointer to filename of schedule table.

    &schedule-table       ( -- addr )
      Pointer to schedule table.

    &options-table        ( -- addr )

      Size of table header (5 cells).

    init-table            ( /table -- &table )
      Create and initialize a table.

    >table-aptrs          ( &table -- addr )
      Get address of pointer list.

    >record-size          ( &table -- addr )
      Get record size.

    >#records             ( &table -- addr )
      Get number of records.

    table-size            ( &table -- bytes )
      Get total table size.

    get-sizes             ( &table -- list records record-size )
      Get all table sizes.

    .table-props          ( &table -- )
      Display table properties.

  Record access:
  --------------
    nt>aptr               ( n &table -- addr )
      Get pointer address from record n.

    rt>record             ( rel-addr &table -- &record )
      Get record from relative address.

    >table-record         ( #record &table -- &record )
      Get record address from record number.

    nt>record             ( n &table -- &record )
      Get record from record n.

  Key comparison:
  ---------------
    xchange               ( a1 a2 -- )
      Exchange two values.

    >key                  ( ra -- key-start )
      Get key start address.

    key-len               ( ra -- len )
      Get key length.

    <>=                   ( n1 n2 -- -1|0|1 )
      Compare two integers.

    f<>=                  ( f1 f2 -- -1|0|1 )
      Compare two floats.

    cmp-cells             ( cand1 cand2 by -- n )
      Compare two cell values.

    cmp-floats            ( cand1 cand2 by -- n )
      Compare two float values.

    cmp$                  ( cand1 cand2 by -- n )
      Compare two strings.

  Key definition:
  ---------------
    Ascending             ( key -- key )
      Set key to ascending order.

    Descending            ( key -- key )
      Set key to descending order.

    $sort                 ( key -- )
      Set key for string sorting.

    bin-sort              ( key -- )
      Set key for integer sorting.

    float-sort            ( key -- )
      Set key for float sorting.

    key:                  ( -- )
      Define a sort key at compile time.

    by[                   ( R: -- #stack )
      Start key list (compile time).

    ]by                   ( R: #stack -- )
      End key list (compile time).

  Sorting:
  --------
    CmpBy                 ( cand1 cand2 bystack #keys -- flag )
      Compare two records using multiple keys.

    xdrop                 ( nx..n1 #n -- )
      Drop n items from stack.

    gap*3                 ( #records -- #records gap )
      Calculate shell sort gap.

    table-sort            ( keyx..key1 #keys &table -- )
      Sort table using shell sort algorithm.

  File operations for sorted tables:
  ----------------------------------
    create-file-ptrs      ( name -- )
      Create file for pointers.

    open-file-ptrs        ( name -- handle )
      Open file for pointers.

    extend-file           ( size handle -- )
      Extend file to given size.

    add-ptrs              ( aptrs record-size #start #end -- )
      Add pointers to table.

    build-ptrs            ( aptrs record-size #records -- )
      Build all pointers.

    allocate-ptrs         ( #records -- &aptrs )
      Allocate memory for pointers.

  Usage example:
  --------------
    \ Define keys
    0 1 cells key: key1
    1 1 cells key: key2
    
    \ Sort table
    key2 key1 2 &table table-sort

    \ Display sorted table
    .schedule-sorted
